---## 🚀 Featured project

### 🫀 CVD Risk Detection App
> A patient-facing web app that predicts cardiovascular disease risk using a CNN trained on clinical PPG-BP data — **95% accuracy**.

Built on AHA Blood Pressure classification guidelines. Gives personalised precautions when risk is detected.
**Stack:** Python · TensorFlow · CNN · Scikit-learn · HTML/CSS/JS
🔗 [Live Demo](https://vysh30.github.io/cvd-detection-app/) · [Source](https://github.com/vysh30/cvd-detection-app)
